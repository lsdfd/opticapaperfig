# 全文统一，逐图有别

**统一视觉词汇，按论点改变句法。** 全文像同一个团队完成；每张大图有自己的职责。不能把“顶刊风格”理解为所有图套同一个网格，也不能为了变化破坏对照的一致性。

## 哪些固定，哪些变化

| 全文固定 | 随大图论证任务变化 |
|---|---|
| 字族、最终字号层级、数字/符号写法 | 主图与辅助图的面积比例 |
| 同一物理对象的颜色与线型含义 | 并置、流程、矩阵、跨行主图、局部放大等构图 |
| 数据线/轴线/引线的粗细层级 | 观看路径和信息密度 |
| 面板编号、图例、单位、比例尺习惯 | 示意图/照片/曲线/场图的组合 |
| 光路的箭头、结构材质、视角约定 | 全宽光路、二维机制、多尺度结构、统计对照等叙述方式 |
| 图像真实颜色与科学基准 | 当前重点可获得局部强调，不能另立一套随意色彩含义 |

相同量的可比色阶尽量统一；不同量不共色条。特定图需要换范围时明确标注，不能为追求色调统一把差异藏掉。全文允许几种有明确用途的视觉模式，例如白底定量图与黑底光场图，并统一周围的编号、字族和标注。

## 先排文章，再排面板

把每张已有大图写成四项：**本图要证明什么／承接前图哪个问题／用哪些现有证据／看完还剩什么问题**。重复论点可合并；缺少证据只标缺口，不自行编造。
以下是器件论文的一种可能顺序，不是必须画五张：

| 图的职责 | 读者问题 | 对应的空间组织 |
|---|---|---|
| 核心能力与机制 | 新在哪里，靠什么实现？ | 大场景或原理对比＋小局部说明 |
| 设计依据 | 参数为何这样选，机制是否站得住？ | 机制/参数扫描/场图，形成推导路径 |
| 制备与实验验证 | 做出来了吗，预测和测量一致吗？ | 多尺度实物→光路→仿真/实测对照 |
| 性能与边界 | 好多少，在哪些条件下成立或失效？ | 同条件矩阵＋剖面/统计/误差，保留失败区域 |
| 应用与意义 | 这种能力解决了什么实际问题？ | 结果图占主导，关键基准与量化结果在侧 |

理论论文可围绕“现象→解释→推导→边界”；计算工作可围绕“问题→方法→公平基准→消融/泛化”。顺序服从已有论证，不强行填图。

## 同一篇真实论文里的统一与变化

- **N09 / Shape optimization（Light）**：F1用黑白结构对比解释设计自由度，F2用闭环流程说明怎么优化，F8用蓝橙曲线回答是否有效。三种版式各尽其职，字体与克制的图形语言相容；颜色只在需要区分物理角色时出现。[原文](https://www.nature.com/articles/s41377-024-01629-5)
- **N04 / Plasmonic biosensor（Nature Photonics）**：F1机制＋跨尺度结构，F2电光表征，F4检测结果与校准。不同尺度和数据类型改变了构图，ROI与对应谱线等局部关系仍靠稳定编码连接。[原文](https://www.nature.com/articles/s41566-025-01708-y)
- **O08 / Chromatic dispersion（Optica）**：F1二维机制比较，F2预测与设计，F5实验焦场和剖面验证；论证从“可以怎样控制”走到“实际控制成什么”。不是把全篇做成一组同样的小曲线。[原文](https://authors.library.caltech.edu/records/nnf8v-92988)

这些是对实际图像的设计解读；不把个别论文归纳成所有顶刊的必要条件。图库提供上述可再分发的图片或原文入口。

## 改代码时怎么落实

先从现有清晰图中抽取全文共用style，把字族、字号、线重、色彩角色集中配置；每张图单独决定layout。已有颜色含义有冲突时记录并统一，不能只调当前文件让别处失配。
修改某张图后，同时看它本身和全篇缩略图：它是否一眼属于这篇文章，又是否有清楚而独立的任务？把每张图的一句话串起来，是否构成论证，而不是图型清单？
相同任务可以复用版式；同一大图内部的公平对照尤其应整齐重复。变化必须有理由，不为了“不一样”强行改角度、颜色或尺度。只收到一张图时可做局部优化，并说明尚未检查全文一致性。
