# 视觉参数与细节

以下是skill的**设计建议值**，不是对截图的精确测量，也不是各期刊统一要求。证据锚点：N01、N02、N04、N09、N12、O02、O07–O10，见evidence-atlas.md。

## 字体、符号与层级

| 元素 | 通用／Optica草稿起点（最终尺寸） | 原则 |
|---|---:|---|
| 轴名、短标题 | 8 pt | 黑灰文字；单位明确；标题只写必要条件 |
| 刻度、图例、色条 | 7 pt | 不与轴名大小悬殊 |
| 面板编号 | 9 pt粗体 | 全文统一(a)或a，通常左上同锚点 |
| 次级注释 | 6.5–7 pt | 长说明移入图注 |
| 字族 | Arial / Helvetica | 检查实际安装；缺字时声明替代 |
| Nature制作配置 | 见journal-profiles.md | 不套通用字号 |

- 以最终尺寸判断：178 mm图缩到89 mm时字也减半；dpi不弥补小字。每图最多三个主要字号层级，避免全粗体。
- 变量斜体、单位与说明性下标正体；如λ (nm)、x (μm)、Intensity (a.u.)、Phase (rad)。a.u.与归一化不是自动等义。
- 区分ν/v、l/1、负号/连字符、μ/u，检查上/下标、π、×、度号、矢量和复数符号。
- 黑底编号用白色或移到白边；不默认彩色圆圈编号。大型子阵列用共同编号＋行列条件，避免几十个小字母。
- 小数位依精度和刻度间距；指数倍率统一，减少每刻度重复长数字。

## 线、点、箭头与轴

| 元素 | 建议起点 |
|---|---:|
| 数据主线 | 1.0–1.3 pt |
| 辅助/拟合/基准线 | 0.7–1.0 pt，必要时虚线 |
| 坐标边框、刻度 | 0.6–0.8 pt |
| 散点直径 | 3–4 pt |
| 误差条、引线、ROI框 | 0.6–0.9 pt |
| 比例尺 | 1.2–2.0 pt；长度来自校准 |
| 刻度长度 | 2.5–3.5 pt；朝向一致 |

- 理论连续线＋实验点是起点；密集实测光谱可用细线，不强行下采样。线型/符号冗余编码，重叠处可用空心点。
- 误差不能缩图后消失；注明SD、SEM、CI或仪器误差及n。不要编造误差带。
- 谱线可用两边框/四边框；空间图宜保留完整范围。去边框不是普遍高级感。
- 网格默认关；物理零线、共振位置、带隙可保留；读值确需网格时细浅灰。
- 箭头要有明确对象；传播、偏振、尺寸、数据流用不同约定。双纵轴必须确有不同物理量，优先考虑上下共享x轴。

## 颜色系统

建议离散色（自行选定，非论文吸色）：蓝#0072B2、朱橙#D55E00、蓝绿#009E73、紫红#CC79A7；灰#666666作基准。不必用满四色。

| 数据性质 | 起点 | 禁止混淆 |
|---|---|---|
| 非负强度/效率/计数 | cividis、viridis或magma | 发散色暗示不存在的负值 |
| 实部/虚部/正负差值/Stokes | RdBu_r等发散色，中心0 | 模长与带符号场量混用 |
| 包裹相位/周期角度 | twilight等循环色，固定完整周期 | 顺序色制造周期接缝 |
| SEM/结构照片 | 灰度/原色 | 默认伪彩；着色需标注 |
| RGB通道/可见波长 | 物理红绿蓝＋通道/波长标签 | 为品牌色破坏物理编码 |
| 缺失/遮挡/无效区 | 显式mask、灰色或透明＋说明 | 把缺失填为零 |

- TE蓝、TM橙等含义贯穿全篇；仿真/实验再用线型区别，不交换颜色。
- 色条写量、单位、归一化基准；端点和关键中点足够，对数写清log或dB参考值。
- 仅同量、同单位、同norm、同范围的面板共用色条；色条独立分列，避免自动挤窄其中一图。
- 不凭配色名字宣称色盲友好；做灰度/色觉缺陷预览，检查曲线、ROI和明度。浅黄线在白底常难读。
- 保留原始照片的物理颜色，不任意调成“统一色调”；连续色图不能用于没有顺序的类别。

## 空间与留白

- 草稿可从85 mm单栏、178 mm双栏起步，明确为本地选择；最终宽度按期刊文字区核查。
- 面板间距可从横4–7 mm、纵6–10 mm起步，为轴标和标题调节；检查最终绘图区，不仅容器框。
- 留白表达分组，不默认粗盒子包每图；不为填空拉伸照片、光斑或SEM。
- 共享图例/色条/列标题单独留位置；ROI与放大框颜色一致、连线简短。inset不可遮峰、误差带和比例尺。
- 3D用于结构/光路，不用于仅比较数值的柱图；材质、层厚和坐标清楚，控制反光、阴影与透视。
