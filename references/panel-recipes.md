# 组图配方

先写读者应判断的一句话，再选面板。以下是样本归纳，不是固定模板；缺证据就标待补，不填假数据。

| 问题 | 面板组织 | 原图锚点 |
|---|---|---|
| 器件为何有效 | 上方结构/机制，下方响应、SEM、效果 | N01 F2；N04 F1；O07 F2 |
| 优化是否有效 | 流程→仿真/实测并排→同指标前后变化 | N09 F1/F2/F8 |
| 预测与测量是否一致 | 行固定条件，列仿真/实测/误差 | O02 F4/F5；O08 F5 |
| 多波长聚焦/色散 | 上方焦距/效率曲线，下方逐波长传播图/PSF/剖面 | O08 F5；O09 F6；N10 F1/F2 |
| 偏振/Mueller测量 | 概念和结果分开，4×4矩阵按i,j排，共享有定义的色阶 | N02 F2/F5 |
| 光谱传感 | 器件和ROI→原始谱/理论→标定与误差 | N04 F4 |
| 多维成像改进 | 行方法、列场景；同ROI；旁边定量指标 | N12 F4；N10 F7 |
| 场解释机制 | 结构轮廓＋场图＋物理曲线，剖面对应热点 | N07 F2；N11 F2 |
| 鲁棒性边界 | 曝光/计数/遮挡按序排列，保留退化 | O10 F11；N06 F5 |
| 原理对比 | 等宽概念列、统一箭头、少量符号 | O08 F1；N09 F1 |

主文图序可从“核心能力和机制→单元/算法证据→实验与性能→应用/对照/局限”起步，不规定必须四张。理论工作围绕机制与验证，系统工作围绕装置、标定、应用。补充材料承接重复参数扫描，不能藏起主张必需的对照。

一大机制图＋三张证据图适于结构；2×3适于等价条件；跨两行大图适于关键传播或成像。光路可全宽，不强迫等大小。
同一图不能无说明在不同区域交换“列=仿真/实测”与“列=TE/TM”。色条加入后测实际绘图区；过密先减少重复标注或拆图，再考虑缩字。
编号按阅读顺序；图注依次解释条件、编码、归一化、比例尺、误差，不夸大结果。
